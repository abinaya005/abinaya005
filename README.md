### 🌟 Featured Projects

#### 🔹 [MCP Browser Automation](https://github.com/abinaya005/MCP-Browser-Automation)
An AI-driven browser automation system combining the **Groq API** with **Selenium**, letting an LLM plan and execute web actions autonomously instead of relying on hardcoded scripts.

#### 🔹 [Symptom Checker AI](https://github.com/abinaya005/-Symptom-Checker-AI)
An NLP/ML-based health assistant that takes natural-language symptom descriptions and suggests likely conditions, built to explore practical applications of NLP in healthcare.

#### 🔹 [Netflix Movie Recommendation System](https://github.com/abinaya005/Netflix-Movie-Recommendation-System)
A content-based recommender built with **Python, pandas, and scikit-learn** — uses TF-IDF vectorization and cosine similarity to suggest the top 5 similar movies without needing user ratings or history.

#### 🔹 [Emotion Detector](https://github.com/abinaya005/Emotion-Detector)
A Python-based model that detects emotional tone from text/input data.
